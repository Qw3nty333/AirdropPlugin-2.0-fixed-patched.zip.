
# Как получить JAR — максимально просто

1. Установи JDK 21.
2. Распакуй этот ZIP.
3. Открой папку проекта.
4. Дважды нажми `build.bat`.
5. Подожди. При первом запуске скрипт сам скачает Gradle.
6. Готовый файл будет здесь:

build\libs\AirdropPlugin-2.0.0.jar

Его нужно положить в папку plugins твоего Paper-сервера.

Если Windows покажет ошибку, НЕ закрывай окно. Скопируй текст ошибки и отправь его мне.
