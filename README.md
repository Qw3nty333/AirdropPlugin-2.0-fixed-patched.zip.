# AirdropPlugin 2.0 — Paper 1.21.10

## Что добавлено в 2.0

- Автоматический спавн по таймеру.
- Лимит одновременно активных аирдропов.
- Весовая случайная редкость.
- Случайная безопасная точка в выбранном мире.
- Голограммы над каждым аирдропом на ArmorStand Marker.
- Таймер открытия и прогресс-бар.
- GUI `/airdrop gui`.
- В GUI ЛКМ по аирдропу телепортирует администратора к нему.
- Звуки и частицы при появлении, закрытии купола и открытии.
- Ультра-легендарный купол начинает восстанавливаться за 3 минуты до открытия.
- Ультра-купол постепенно закрывается.
- Внутри закрытого купола можно оказаться эндер-жемчугом или плодом хоруса.
- Защита территории от ломания и взрывов.
- Реальный двойной сундук, клиенту показываем визуальный блок редкости.
- Лут перемещается каждые 0.3 секунды (6 тиков).
- Открытие через 7–10 минут.
- Сохранены все основные редкости, тематики и кастомные предметы из 1.0.

## Сборка

Java 21 + Gradle 8+:

```bash
gradle build
```

JAR появится в:

```text
build/libs/AirdropPlugin-2.0.0.jar
```

## Важно

В `config.yml` укажи правильный мир:

```yaml
auto-spawn:
  world: world
```

Автоматический аирдроп по умолчанию может заменить блоки в круге радиусом 20. На боевом сервере сначала протестируй это на отдельном мире.

`Protection VI` реализуется как unsafe-уровень ванильного Protection с PDC-маркером. `Бур I/II` также маркируется PDC и требует отдельного обработчика BlockBreakEvent, если нужна полноценная механика добычи 5/9 блоков.
